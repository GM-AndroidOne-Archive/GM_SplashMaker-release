GM 5 Plus, GM 8 ve GM 9 Pro için açılış görseli düzenleme aracı.

Yalnızca Linux uyumludur. Cihazınıza uygun branch'ı "git clone https://github.com/GM-AndroidOne-Archive/GM_SplashMaker-release -b branch" ile çekebilirsiniz. branch kısmına GM5PLUS, GM8 veya GM9PRO branchlarından birini yazmayı unutmayın.
Ardından cd GM_SplashMaker-release yapın ve aracın yer aldığı klasöre geçin.

pics/boot.png ve GM 8 için kullanıyorsanız fastboot.png dosyalarınızı düzenleyin, ardından "bash make_splash.sh" komutunu verin.
Kısa süre içerisinde new-splash.img dosyanız hazır olacaktır.
